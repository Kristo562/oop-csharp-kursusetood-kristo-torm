# Kristo Torm - OOP tööd C# keeles

Need on OOP kursusetööd ja kursuseprojekt C# Windows Forms kujul.

## Projektid

- `Torm_OOP_KT1_CSharp` – tervitus, värvi muutmine ja lihtne liitmine

- `Torm_OOP_KT3_CSharp` – täringumäng
